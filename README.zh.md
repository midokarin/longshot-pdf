# Longshot PDF

简体中文 | [English](README.md)

<img src="https://raw.githubusercontent.com/midokarin/longshot-pdf/main/docs/images/download.jpg" alt="Longshot PDF 标志" width="340">

把 Obsidian 笔记截成长图，导出为 PDF、JPG 或 PNG。可以自动分页，也可以保存整篇长图。

## 为什么做这个插件

我最初的需求很简单：把一份 Markdown 笔记导出成 PDF，再转成图片分享。但导出后才发现，阅读视图里显示正常的内容，到了 PDF 中会变样，有些渲染结果甚至会丢失。笔记已经整理好了，却还要花时间处理导出的问题。

既然想保留的是眼前的效果，直接截图应该更合适。于是我做了 Longshot PDF：先把渲染好的笔记截成长图，需要多页时再切分，也能直接保存为图片，省去 PDF 转图片这一步。

这个插件的出发点就是尽可能保留笔记原来的样子，尤其是那些带有公式、图表或自定义样式的内容，方便自己保存，也方便分享给别人。

下面这张图记录了我当时遇到的渲染差异：每组左侧是软件内预览，右侧是当时导出的 PDF。渐变、阴影和部分图形在导出后发生了变化。

![阅读视图与当时导出的 PDF 对比，展示渐变文字、阴影和图形等渲染差异](docs/images/render-comparison.png)


## 工作原理

插件会在屏幕外按阅读视图的方式渲染笔记，等待图片、公式和图表加载，再截取长图。如果选择自动分页，就根据纸张尺寸和页边距寻找切分位置，最后加入你设置的页眉、页脚或水印。

```text
Markdown 笔记 → 阅读视图渲染 → 长截图 → 分页或保留整图 → PDF / JPG / PNG
```

但截图也有取舍：PDF 中的正文仍然是图片，没有可搜索、可复制的文字层，正文链接也不能点击。

### 与其他导出插件相比

| 插件 | 主要用途 |
| --- | --- |
| Longshot PDF | 将阅读视图截成图片，保存为长图或分页文件，适合分享笔记画面 |
| [Pandoc Plugin](https://github.com/OliverBalfour/obsidian-pandoc) | 通过 Pandoc 转换为 Word、PDF、ePub、HTML 等格式，适合需要继续编辑或重新排版的文档 |
| [Better Export PDF](https://github.com/l1xnan/obsidian-better-export-pdf) | 增强 PDF 导出，支持预览、大纲书签、页码、页边距、内部链接和多文件合并等功能 |

需要 Word 或 ePub 等格式时，可以考虑 Pandoc；重视 PDF 链接、书签和多篇合并时，可以看看 Better Export PDF。Longshot PDF 更适合想把笔记按阅读时的样子保存成图片的情况。

## 下载与安装

需要 Obsidian 1.4.0 或更新版本。仅支持桌面端，不支持手机和平板。

1. 从[本项目发布页](https://github.com/midokarin/longshot-pdf/releases/latest)下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在 Obsidian 仓库的 `.obsidian/plugins/` 目录下，新建 `longshot-pdf` 文件夹，将这三个文件放进去。
3. 重启 Obsidian，在“设置 → 第三方插件”中启用 Longshot PDF。如果处于受限模式，先关闭受限模式。

安装后的目录应是这样：

```text
你的仓库/
└── .obsidian/
    └── plugins/
        └── longshot-pdf/
            ├── main.js
            ├── manifest.json
            └── styles.css
```

更新时，替换这三个文件，再关闭并重新开启插件。不要删除 `data.json`，里面保存着你的设置。

### 界面语言

插件跟随 Obsidian 的语言设置：中文环境显示简体中文，英文及其他语言环境显示英文。修改 Obsidian 的语言后，按提示重启应用即可。

笔记正文、填写的水印文字、作者信息和自定义模板名称会保留原文。下面的截图展示的是中文界面，英文界面提供相同的功能。

## 开始使用

### 快速设置页

打开一篇 Markdown 笔记，点击 Obsidian 左侧工具栏的相机图标。

1. 选择“自动分页”或“长截图”，再选择 PDF、JPG 或 PNG。
2. 按需调整输出质量、保存位置和水印。自动分页时，还可以设置纸张和页边距。
3. 点击“开始导出”。如果想先检查分页位置，点击“预览分页…”。

文件默认保存在当前笔记所在文件夹。设置会自动保存，下次导出不必重新填写。

<img src="https://raw.githubusercontent.com/midokarin/longshot-pdf/main/docs/images/quick-settings.jpg" alt="快速设置页：选择长截图和 PDF 格式，设置水印与输出位置" width="620">

### 详细设置页

点击“更多设置…”，或打开“设置 → Longshot PDF”，可以找到全部选项。

| 分栏 | 设置内容 |
| --- | --- |
| 截图 | 内容宽度、截图倍率、主题配色、是否包含笔记标题 |
| 纸张 | 纸张尺寸、四边页边距、底色和边框 |
| 页眉页脚 | 文字内容、对齐方式，以及页码等变量 |
| 分页 | 智能分页、标题和图片的切分处理、强制分页标记 |
| 水印 | 文字或图片水印、作者署名、头像和样式模板 |
| 输出 | 导出类型、格式、质量和保存位置 |

自动分页会使用纸张、页边距和页眉页脚设置。长截图 PDF 使用所选纸张的宽度和四周页边距，高度随内容延伸，不切分，也不添加页眉页脚。长截图 JPG / PNG 直接保存整篇画面。

![详细设置页的截图分栏：渲染宽度、截图倍率、配色与等待时间](docs/images/full-settings.jpg)

也可以在命令面板中搜索 `Longshot PDF`，选择分页 PDF、每页图片、长截图或单页长图 PDF。导出命令会直接使用已保存的设置，不再打开快速设置页。

## 核心功能

### 自动分页

长笔记可以按 A4、A5、B5、Letter 或自定义纸张尺寸拆成多页。

开启智能分页后，插件会尽量在内容块之间切分，避免只把一个标题留在页尾。能够放进一页的图片也会尽量保持完整；图片本身超过一页高度时，仍可能被切开。

分页不合适时，可以在预览中手动调整断点。想明确指定某处换页，也可以开启“强制分页标记”，在笔记中单独写一行 `///`：

```markdown
这一部分放在前一页。

///

这一部分从新的一页开始。
```

代码块里的 `///` 不会触发分页。

### PDF、JPG 和 PNG

同一篇笔记可以导出为多页文件，也可以保留成长图：

| 导出类型 | PDF | JPG / PNG |
| --- | --- | --- |
| 自动分页 | 一个多页 PDF | 每页一张图片 |
| 长截图 | 一个单页长图 PDF，不切分 | 一张完整长图 |

想让图片小一些，可以选 JPG。文字、细线或图表较多时，PNG 的无损压缩更合适。需要把多页内容放在一个文件里，则可以选 PDF。

### 水印与署名

在快速设置页打开水印开关，再到详细设置页的“水印”分栏填写内容。

可见水印可以用文字，也可以用图片。位置、大小、透明度和旋转角度都能调整，还可以铺满整页。

如果只是想留下名字，可以开启作者署名。例如，姓名填写 `Lin`，附加文字填写 `123456@qq.com`，再按需添加头像。内置 10 套透明无底色的样式模板，点击小样即可套用；小样由实际绘制代码生成，方便挑选。

水印和署名分别控制，可以只开其中一个。分页导出时，署名放在每页正文下方；长截图导出时，放在整张图片底部。

![水印设置页：可见水印、作者信息及预览效果](docs/images/watermark-settings.png)

还有一个可选的像素级隐水印功能。使用它时建议导出 PNG，JPG 压缩可能破坏隐藏信息。


## 文件访问与隐私

导出在本机完成。选择库外文件夹时，插件通过 Node.js 文件系统接口创建目标文件夹、写入导出文件；头像和水印也可以读取你指定的库外图片。同名导出文件会被覆盖。

隐水印校验只读取你在文件选择框中选中的 PNG。批量导出读取所选文件夹及其子文件夹中的笔记。插件不会在后台扫描整个笔记库，也不会上传笔记；笔记里已有的远程图片链接可能在渲染时联网加载。

由于支持库外导出和图片读取，安全检查工具仍可能提示“直接访问文件系统”。
